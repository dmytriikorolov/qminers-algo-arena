# Minimal offline starter

It runs with stock Python 3.10+ and establishes four executable examples. They intentionally do **not** claim to be competitive or implement the official API. Codex should improve them into separate reproducible, validated vertical slices. The market example has an arbitrary synthetic fill model; it must **not** be mistaken for exchange-grade execution.

`python3 -m unittest discover -s starter_tests -v`

`python3 -m starter_arena all-demos`
